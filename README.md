# TaskNote - To-Do and Notes App

## Project Overview

TaskNote is a React-based productivity application that combines
a To-Do application and a Notes application in a single interface.

The project was developed to demonstrate React fundamentals,
component-based architecture, state management, event handling,
React Hooks, and modern JavaScript concepts.

## Features

### To-Do App

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Display Completed/Pending status
- Filter tasks by All, Pending and Completed
- Add due dates
- Store tasks using Local Storage

### Notes App

- Create new notes
- Edit notes
- Delete notes
- View notes in an organized layout
- Search notes
- Categorize notes
- Display note timestamps
- Store notes using Local Storage
